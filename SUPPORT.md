# Support

## Where to ask what

| You want to...                          | Go here                                                                                |
| --------------------------------------- | -------------------------------------------------------------------------------------- |
| Report a reproducible bug               | [Open an issue](https://github.com/outputease-inc/toolkit/issues/new/choose) (Bug)     |
| Request a feature or preset             | [Open an issue](https://github.com/outputease-inc/toolkit/issues/new/choose) (Feature) |
| Report a security vulnerability         | Email `security@outputease.com`. See [SECURITY.md](./SECURITY.md).                     |
| Ask a "how do I" question               | [Open a Discussion](https://github.com/outputease-inc/toolkit/discussions) (Q&A)       |
| Share a project built with the toolkit  | [Open a Discussion](https://github.com/outputease-inc/toolkit/discussions) (Show & Tell) |
| Get help with the broader OutputEase work | Email `contact@outputease.com`.                                                       |

## Before filing a bug

1. Run `outputease --version` and confirm you're on the latest published
   release. The toolkit is pre-1.0 and ships frequent fixes.
2. Try `outputease update` if you're on an older scaffolded project; many
   issues resolve themselves once tooling is current.
3. Search existing issues and Discussions. Someone has probably hit it.

When you file, include the toolkit version, your OS, Bun/Node version, and
a minimal reproduction.

## Response expectations

This is an open-source project maintained by a small team. We read every
issue and aim to triage within a few business days, but we cannot promise
SLA-style response times. Security reports get priority.
